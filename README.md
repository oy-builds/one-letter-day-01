# One Letter for Your Day — "H"

A one-letter diary entry for the make.fun bounty *One Letter for Your Day*.

The entry is a single letter: **H** — for *hungover*. The day after,
reported in one character: the pounding head, the sunglasses indoors,
the slow regret. Vivid, a little funny, and true.

`main.ts` (Node, no dependencies) writes exactly that one character —
no newline, nothing else — to `/output/entry.txt`, then reads it back
to verify the file holds precisely one letter before exiting.
